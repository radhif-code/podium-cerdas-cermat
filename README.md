# Podium Pulse Showdown

Create a modern, elegant, glassmorphism realtime scoreboard web application for a quiz competition.

## Theme

Do NOT use a dark theme.

Use a soft premium pastel gradient inspired by Apple and modern event websites.

Background should consist of smooth blurred gradients using:

- White
- Soft Peach
- Light Orange
- Soft Pink
- Lavender
- Sky Blue
- Cyan

The background should feel clean, elegant, cheerful, and premium.

Use glassmorphism cards with:

- white transparency
- blur
- soft shadows
- rounded corners
- smooth animations

No black backgrounds.

## Layout

Split the page into two sections.

### Left

Operator Panel

Each team card contains:

- Team Logo
- Team Name
- Current Score
- Minus button
- Reset button
- Plus button

Buttons should be large, rounded, colorful and animated.

Allow operator to:

+1
+5
+10
+20

-1
-5
-10
-20

Reset Score

Manual Input Score

---

### Right

Realtime Leaderboard

Display ranking automatically.

Use podium style.

🥇 First Place

Large center card with crown animation.

🥈 Second Place

Left.

🥉 Third Place

Right.

Remaining teams appear below in ranking order.

Each team card displays:

- Logo
- Team Name
- Score
- Progress animation

Confetti

Organizer can customize:

- Competition Name
- Theme Color
- Background
- Number of Teams
- Team Names
- Team Logos
- Initial Scores
- Score Increment Buttons
- Maximum Score

Everything editable without coding.

## Style

The interface should feel like a premium national quiz competition broadcast.

Use modern glassmorphism, soft gradients, smooth transitions, floating effects, elegant spacing, and beautiful typography.
